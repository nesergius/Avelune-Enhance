# Avelune Enhance UI Overhaul v10.1 — Windows build-gate fix

## Исправленная ошибка

UI v10 расширил боковую область до 396 px на стандартном окне 1366×768, но packaged UI probe продолжал использовать диапазон UI v9: 320–380 px. Поэтому приложение, установщик, Portable, вставка из буфера и остальные проверки проходили, а финальный release-gate ошибочно возвращал `sidebarReadableWidth:false`.

## Новая проверка

Проверка читает активную CSS-переменную `--sidebar-width` и сравнивает её с фактической шириной DOM с допуском 2 px. Дополнительно сохранены безопасные абсолютные границы 340–410 px, поэтому gate по-прежнему обнаруживает свёрнутую, обрезанную или чрезмерно широкую панель.

Это исправление не ослабляет проверки прокрутки, рабочей области, вставки из буфера, производительности или запуска упакованного приложения.
