# RC5.2 runtime QA checklist

## Автоматические packaged gates

Ожидаются два отчёта:

- `RC5.2-PACKAGED-UI-PROBE-1366x768.json`
- `RC5.2-PACKAGED-UI-PROBE-1280x720.json`

В каждом должны быть `passed: true`, `clipboardPreviewPassed: true`,
`defaultControlsNoScroll: true` и `scrollPerformancePassed: true`.

## Основной поток

- [ ] Вставка `Ctrl+V` показывает изображение, имя и разрешение без
      «Предпросмотр недоступен».
- [ ] Две быстрые вставки подряд оставляют последнюю картинку.
- [ ] Выбор JPG/PNG/WebP кнопкой показывает preview.
- [ ] Drag-and-drop JPG/PNG/WebP показывает preview.
- [ ] Документ, canvas и область изображения не прокручиваются.
- [ ] При 1366 × 768 параметры по умолчанию помещаются без scroll.
- [ ] При 1280 × 720 параметры по умолчанию помещаются без scroll.
- [ ] После открытия Advanced прокручивается только левая панель.
- [ ] Скролл колесом и precision touchpad начинается и останавливается сразу.
- [ ] Canvas не двигается и не дрожит во время scroll.
- [ ] Все семь профилей выбираются.
- [ ] 2×, 3×, 4× и PNG/JPG/WebP работают.
- [ ] Обработка, отмена и повторный запуск работают.
- [ ] До/После движется плавно и доходит до краёв.

## DPI и минимальное окно

Повторить при 100%, 125%, 150%, 175% и 200%. На 1024 × 640 и 860 × 640
допустим scroll только внутри панели параметров.

## Длительная проверка

- [ ] 50 последовательных открытий/очисток preview без роста RAM.
- [ ] 25 вставок из буфера без смешивания файлов.
- [ ] 50 переключений профиля без layout shift.
- [ ] Интерфейс остаётся отзывчивым во время работы engine.
