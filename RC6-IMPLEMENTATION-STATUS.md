# RC6 — статус внедрения рекомендаций 1–8

## 1. Разные проверенные модели — внедрено

Добавлены RealESRNet x4plus и AnimeVideo v3 2×/3×/4×. Существующие Natural и Art проверяются на byte-for-byte соответствие официальным файлам. Все ресурсы закрепляются SHA-256.

## 2. Локальный Auto Profile — внедрено

Анализ выполняется в renderer без отправки изображения в сеть. Учитываются контуры, насыщенность, шум, JPEG-блоки, яркость, размер изображения и VRAM. Пользователь получает объяснение рекомендации и может изменить её.

## 3. Адаптивный просмотр результата — внедрено

Старый отдельный preview области удалён из публичного RC6. Текущий интерфейс использует единое рабочее поле с безопасным file/clipboard preview, точным ползунком «До/После» и проверкой геометрии на 100%, 125% и 150% DPI.

## 4. Smart Queue — внедрено

Поддерживаются индивидуальные состояния, прогресс, pause/resume, retry failed, remove, open output, continue-on-error, skip-existing и восстановление очереди после перезапуска.

## 5. Восстановление лиц — внедрено в консервативном режиме

Включён локальный второй проход RealESRNet. Это безопасная базовая реализация, но не специализированный GFPGAN и не генеративная реконструкция лица. Интерфейс прямо сообщает об этом.

## 6. Профессиональная точность файлов — частично внедрено

Реализовано сохранение совместимых EXIF/XMP/IPTC/ICC-блоков для JPEG, PNG и extended WebP. Ошибка метаданных не уничтожает готовый результат.

Не включены в RC6: TIFF и настоящий 16-битный AI-пайплайн. Текущий NCNN runtime не обеспечивает проверенный сквозной тракт; имитация поддержки была бы вводящей в заблуждение.

## 7. GPU AutoTune — внедрено

Добавлен benchmark fixture, измерение вариантов tile size и автоматическая рекомендация. При OOM/device-lost движок последовательно повторяет задачу с 256, 128 и 64 px.

## 8. Build/QA gate — внедрено

Проверяются 1280×720, 1366×768 и 1920×1080 при 100%, 125% и 150% scale factor. Сохраняются JSON-метрики и PNG-скриншоты. При визуальном провале готовые артефакты перемещаются в `QA-FAILED`, а не удаляются.

## Дополнительно

Обновлены логотип и icon assets. Все функции проходят автоматические тесты исходников. Финальная Windows-runtime проверка выполняется через `tools\build-rc6-release.ps1` или tag-based GitHub Actions release build.


## Исправление загрузки RealESRNet

Windows-пакет NCNN v0.2.5.0 не содержит `realesrnet-x4plus`. Builder теперь оставляет актуальные AnimeVideo-v3 из v0.2.5.0, а RealESRNet получает из официального v0.2.3.0 с обязательной проверкой SHA-256 каждого файла.
