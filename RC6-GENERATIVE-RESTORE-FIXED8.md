# RC6 FIXED8 — Generative Restore

Добавлен отдельный добровольный облачный режим для экстремально плохих фотографий.

Пайплайн:
1. OpenAI GPT Image выполняет генеративную реконструкцию с `input_fidelity=high` и `quality=high`.
2. Локальный Real-ESRGAN/TTA доводит разрешение до выбранного размера.
3. Совместимые метаданные исходного файла возвращаются в результат.

Ключ OpenAI API хранится через Electron `safeStorage` и не записывается открытым текстом. Обычные профили остаются полностью локальными.

Ограничение: утраченные детали реконструируются правдоподобно и могут не совпадать с реальным оригиналом.
