# Avelune Enhance 2.0.0 RC5.2

RC5.2 исправляет две подтверждённые runtime-проблемы RC5.1.1:
предпросмотр изображения из буфера обмена и нестабильное ощущение прокрутки
панели параметров.

## Предпросмотр изображения

- вставленное изображение сразу получает renderer-owned `blob:` preview;
- после сохранения путь и preview связываются UUID-запросом;
- несколько быстрых вставок не могут перепутать изображение и путь;
- устаревший ответ не заменяет последнюю вставку;
- неиспользованные object URL освобождаются автоматически;
- при недоступном `file://` используется проверенный бинарный IPC fallback;
- packaged UI probe выполняет настоящий путь: paste → IPC save → visible preview;
- probe требует реальные размеры `1 × 1`, а не только отсутствие ошибки.

## Прокрутка и компоновка

- при 1366 × 768 и 1280 × 720 основной workflow помещается без прокрутки;
- документ, canvas, preview и drop-zone не прокручиваются;
- прокрутка появляется только после раскрытия расширенных параметров или в
  действительно маленьком окне;
- сохранена нативная compositor-прокрутка Chromium;
- удалены универсальные descendant-правила и постоянные compositor hints;
- обычное окно снова throttled в фоне;
- packaged probe измеряет p95/max frame time и layout shift во время прокрутки;
- добавлен второй packaged UI gate для 1280 × 720.

## Дополнительная доводка

- исправлено оформление toast: заголовок, пояснение и кнопка закрытия больше
  не слипаются;
- профиль в компактном hint отображается без лишнего повторения `Avelune`;
- сохранена прозрачная пометка: 2 проверенные AI-модели и 5 профилей;
- Source Snapshot по-прежнему создаётся Node.js stager без `robocopy`.

RC5.2 остаётся release candidate. Публичная публикация заблокирована до
полного Windows PASS, Authenticode и финального security scan.
