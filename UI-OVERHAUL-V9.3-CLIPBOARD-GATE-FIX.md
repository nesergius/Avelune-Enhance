# UI Overhaul v9.3 — Clipboard release-gate fix

## Симптом

Windows-сборка и packaged startup probe проходили, но UI probe завершался кодом 24 при `clipboardPreviewPassed:false`. Диагностика при этом уже показывала успешное состояние: `srcScheme:"blob"`, `naturalWidth:1`, `naturalHeight:1`, `complete:true`.

## Причина

Между последней итерацией `waitFor` и сбором диагностики существовала узкая гонка событий. Таймаут мог завершиться непосредственно перед commit уже декодированного blob-изображения. Дополнительная проверка текста разрешения также была лишней и зависела от отображения символа `×` в кодировке консоли Windows.

## Исправление

- Введён единый предикат `clipboardPreviewReady()`.
- Проверяются только фактические признаки успешного превью: `complete`, размеры 1×1 и `blob:` URL.
- После `waitFor` создаётся единый финальный снимок DOM, из которого одновременно формируются диагностика и итоговый флаг.
- Текст `#source-resolution` исключён из release-gate.

## Область изменений

Исправлена только автоматическая packaged UI probe. Runtime приложения, обработка изображений, модели и пользовательские настройки не изменены.
