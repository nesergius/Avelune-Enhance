# RC6 prepared-model compliance test hotfix

## Причина остановки сборки

`BUILD_RC6_WINDOWS.cmd` сначала скачивает и проверяет закреплённые официальные модели, а затем запускает `npm test`. Старый тест `models-compliance.test.js` был написан только для состояния исходного архива до загрузки и требовал, чтобы `resources/models` содержал ровно четыре базовых файла.

После успешной подготовки каталог корректно содержит дополнительные AnimeVideo-v3/RealESRNet-файлы и `official-model-manifest.json`. Поэтому тест ошибочно блокировал сборку, хотя загрузчик, SHA-256 и общий resource manifest уже прошли.

## Исправление

Тест теперь принимает только два состояния:

1. **Pristine source** — четыре исходных базовых файла.
2. **Prepared RC6 source** — четыре базовых файла, восемь официальных файлов и `official-model-manifest.json`.

Во втором состоянии дополнительно проверяются:

- точный список файлов без посторонних элементов;
- точный список записей official manifest;
- официальные URL Real-ESRGAN v0.2.5.0 и v0.2.3.0;
- размер и SHA-256 каждого установленного файла;
- закреплённые SHA-256 для RealESRNet;
- соответствие AnimeVideo источнику v0.2.5.0 и RealESRNet источнику v0.2.3.0.

Таким образом проверка происхождения не отключена: она стала согласована с фактическим порядком Windows builder.
